# FastVue-Admin 前端

通用后台开发底座，默认启用系统基础功能与开发示例。详细说明见 [项目 README](../README.md)。

```bash
npm ci
npm run dev          # 精简启动
npm run dev:full     # 含行业和组织示例
npm test
npm run build
```

配置参考 [.env.example](.env.example)。
